

# Enable PDF Downloads in All 3 Demo Pages

## Overview
Add a PitchGauge-branded footer to all PDF exports and wire up the PDF download buttons on all three demo pages using existing static data. No API calls needed.

## Changes

### 1. `src/lib/pdf-export.ts` — Add footer helper + new demo export functions

- Add a shared `addPitchGaugeFooter(pdf)` helper that adds "Generated by PitchGauge — pitchgauge.lovable.app" at the bottom of every page (iterate all pages and stamp footer).
- Add `exportDemoAnalysisToPDF(result, startupName, fileName)` — reuses existing `exportAnalysisToPDF` logic but includes benchmarking section and uses the specified filename. Calls footer helper before save.
- Add `exportDemoComparisonToPDF(results, insights)` — builds PDF with: investment rankings, all 3 startup scorecards with scores/reasoning, strengths/weaknesses per startup, overall recommendation. Saves as `PitchScore_Comparison_Demo.pdf`. Calls footer helper.
- Add `exportDemoBulkToPDF(results, comparisonReport)` — builds PDF with: top 10 ranked startups, sector distribution, overall recommendation. Saves as `PitchGauge_Bulk_Demo.pdf`. Calls footer helper.
- Also retrofit the footer into existing `exportAnalysisToPDF`, `exportComparisonToPDF`, and `exportBulkAnalysisToPDF` functions.

### 2. `src/pages/Demo.tsx` — Enable PDF download button

- Import the new `exportDemoAnalysisToPDF` function.
- Replace the locked "Export" button with a "Download PDF" button that calls `exportDemoAnalysisToPDF(result, result.startupName, activeResult === "text" ? "PitchScore_FinFlow_Analysis.pdf" : "PitchGauge_EcoTrack_Analysis.pdf")`.
- Keep the existing locked badge for JSON/other exports.

### 3. `src/pages/DemoCompare.tsx` — Enable PDF export button

- Import `exportDemoComparisonToPDF`.
- Replace the locked "Export PDF" button (line 208) with a working button calling `exportDemoComparisonToPDF(DEMO_COMPARISON_RESULTS, DEMO_COMPARISON_INSIGHTS)` saving as `PitchScore_Comparison_Demo.pdf`.
- Keep "Save Comparison" button locked behind signup.

### 4. `src/pages/DemoBulk.tsx` — Enable PDF export button

- Import `exportDemoBulkToPDF`.
- Replace the locked "Export PDF" button (line 237) with a working button calling `exportDemoBulkToPDF(DEMO_BULK_RESULTS, DEMO_BULK_COMPARISON_REPORT)` saving as `PitchGauge_Bulk_Demo.pdf`.
- Keep Excel download as-is (it already works). Keep other locked features locked.
